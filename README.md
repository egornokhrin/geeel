# 💻 Персональный лендинг разработчика

Стартовая заготовка сайта-портфолио (Wireframe), собранная из отдельных блоков-компонентов. Проект создан с использованием **React, JavaScript, CSS и Vite**. Сайт объединяет информацию о направлениях деятельности, этапах разработки, проектах и способах связи в минималистичном адаптивном интерфейсе.

## 📖 О проекте

Цель проекта — создать удобную площадку для представления разработчика, его навыков и профессиональных интересов. 

При разработке особое внимание уделено организации компонентов, визуальной структуре страницы и адаптации интерфейса под различные размеры экрана. Проект также служит практическим примером применения React и современных инструментов frontend-разработки.

## ✨ Возможности

- **Главный экран** — представление разработчика и основных направлений деятельности.
- **Навигация** — плавный переход между разделами сайта.
- **Услуги** — описание направлений работы в области программирования и разработки интерфейсов.
- **Процесс разработки** — представление основных этапов выполнения задач.
- **Портфолио** — демонстрация проектов со ссылками на GitHub.
- **Статистика** — отдельный блок с ключевыми показателями.
- **Контакты** — контактная секция с демонстрационной формой.
- **Адаптивная вёрстка** — настройка интерфейса для мобильных устройств и ПК.
- **Компонентная организация** — разделение страницы на независимые React-компоненты.
