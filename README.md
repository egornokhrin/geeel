## 🏗 Архитектура проекта

Проект использует компонентный подход React: интерфейс разделён на компоненты, каждый из которых отвечает за определённый раздел страницы.

**Схема взаимодействия компонентов:**

```text
main.jsx
   │
   ▼
 App.jsx
   │
   ├── Header.jsx
   ├── Hero.jsx
   ├── Stats.jsx
   ├── Services.jsx
   ├── Process.jsx
   ├── Portfolio.jsx
   ├── Contact.jsx
   └── Footer.jsx
main.jsx служит точкой входа приложения и запускает React. Компонент App.jsx объединяет основные части интерфейса.

Основные принципы:

Компонентность: интерфейс разделён на логические части.

Разделение ответственности: каждый компонент отвечает за отдельный участок страницы.

Разделение разметки и оформления: JSX описывает структуру интерфейса, а CSS отвечает за внешний вид.

Расширяемость: новые разделы можно добавлять по мере развития проекта.

Организация стилей:

App.css — стили компонентов и разделов приложения.

index.css — глобальные стили и общие правила оформления.

⚙️ Требования
Для работы с проектом необходимы:

Node.js — среда выполнения JavaScript и пакетный менеджер npm.

Git — система контроля версий.

Для редактирования исходного кода можно использовать Visual Studio Code или любой другой удобный редактор.

🚀 Установка и запуск
Клонирование репозитория:

bash
git clone https://github.com/egornokhrin/geeel.git
Переход в каталог проекта:

bash
cd geeel
Установка зависимостей:

bash
npm install
Команда устанавливает все библиотеки, необходимые для запуска и сборки приложения.

Запуск сервера разработки:

bash
npm run dev
В Windows PowerShell, если команда npm не запускается, используйте:

powershell
npm.cmd run dev
После запуска Vite выведет в терминале локальный адрес сайта (обычно http://localhost:5173/). Открой его в браузере. Во время работы сервера изменения исходного кода будут отображаться автоматически.

🧹 Проверка кода
Для проверки кода с помощью Oxlint выполните:

bash
npm run lint
В Windows PowerShell при необходимости:

powershell
npm.cmd run lint
📦 Сборка проекта
Для создания production-сборки выполните:

bash
npm run build
В Windows PowerShell при необходимости:

powershell
npm.cmd run build
Vite создаст готовые файлы приложения в каталоге dist/.
